Kebijakan Privasi

Berlaku 1 Agustus 2026

Ringkasnya: Fokusin nggak ngumpulin data apapun tentang kamu. Nggak ada akun, nggak ada server, nggak ada analytics, nggak ada iklan, nggak ada pelacak.

Data yang dikumpulkan

Tidak ada. Fokusin tidak mengumpulkan, mengirim, atau menyimpan data pribadi kamu di server manapun. Kami tidak punya server untuk itu.

Data yang disimpan di perangkat kamu

Fokusin menyimpan beberapa hal di penyimpanan lokal browser (localStorage) supaya app-nya berguna:

  • Setelan kamu: durasi timer, tema, pilihan alarm, volume
  • Statistik fokus: jumlah sesi, total waktu, streak harian, riwayat harian
  • Teks catatan tugas yang kamu ketik sendiri

Semua itu tidak pernah keluar dari perangkat kamu. Kami tidak bisa melihatnya. Kamu bisa menghapus semuanya kapan saja lewat Setelan › Hapus semua data, atau dengan membersihkan data situs di browser.

Izin yang diminta

  • Notifikasi (opsional): cuma untuk memberi tahu kalau sesi kamu selesai. Isi notifikasinya dibuat di perangkat kamu sendiri, bukan dikirim dari server.
  • Layar tetap nyala (opsional): supaya layar tidak mati saat timer berjalan.
  • Getar (opsional): getar singkat saat sesi selesai.

Semua opsional dan bisa dimatikan di Setelan. Fokusin tidak meminta akses lokasi, kamera, mikrofon, kontak, atau file kamu.

Layanan pihak ketiga

Fokusin memuat font dari Google Fonts. Saat itu terjadi, Google bisa melihat alamat IP kamu sebagaimana kunjungan web pada umumnya. Selain itu tidak ada layanan pihak ketiga, tidak ada analytics, tidak ada jaringan iklan.

Situs ini dihosting di Cloudflare Pages, yang menyimpan log akses standar untuk keamanan dan operasional.

Anak-anak

Fokusin tidak mengumpulkan data dari siapapun, termasuk anak-anak.

Perubahan

Kalau kebijakan ini berubah, tanggal di atas akan diperbarui. Karena Fokusin dirancang untuk tidak mengumpulkan data, perubahan besar sangat tidak mungkin terjadi.
